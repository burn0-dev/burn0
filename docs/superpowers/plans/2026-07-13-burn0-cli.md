# burn0 CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `burn0` binary — subcommands (`today`, `watch`, `export`, `init`) and the 6-screen Ink TUI — as a thin renderer over `@burn0/core`'s `query/*` API.

**Architecture:** `packages/cli` depends on `@burn0/core` (workspace). One argv router; one read-only DB handle module; commands are plain functions printing to stdout; the TUI is an Ink app polling the DB every 1s. Zero aggregation logic in CLI — everything comes from `core/query`.

**Tech Stack:** Ink 5 + React 18, TypeScript ESM (Ink is ESM-only; the bin ships ESM), tsdown, vitest + ink-testing-library.

**Prerequisite:** `2026-07-13-burn0-core.md` fully implemented (Tasks 1–17 committed). CLI consumes: `openDatabase`, `pruneRetention`, `maybeVacuum`, `loadConfig`, `query.*` (`overview`, `entityList`, `entityDetail`, `traces`, `requestDetail`, `liveTail`, `todaySummary`, `dbStats`), `type StorageDriver`, `type TraceRow`.

## Global Constraints

- Node >= 20.6. CLI is a pure reader: it NEVER inserts rows; it MAY prune (spec: pruning runs on CLI startup too).
- All screens must render inside an 80×24 terminal without crashing.
- Empty database → onboarding screen (install + import snippet), never a blank screen or stack trace.
- `burn0 --web` exits code 1 with exactly: `web dashboard coming soon — use burn0 --cli`
- Subcommand names are frozen API: `today`, `watch`, `export`, `init`.
- Known deviation from design spec §8: the spec's footer "internal error/drop counters" live in the instrumented app's process and are not readable cross-process by the CLI; the footer shows stored request count instead. Persisting counters to the `meta` table is a possible follow-up, not in this plan.
- Commit after every task.

`packages/cli/src/router.ts`:
```ts
export type Command =
  | { kind: 'tui' } | { kind: 'web' } | { kind: 'today' } | { kind: 'watch' }
  | { kind: 'export'; format: 'json' | 'csv'; out: string | null }
  | { kind: 'init' } | { kind: 'help' }

export function route(argv: string[]): Command {
  const [first] = argv
  if (!first || first === '--cli') return { kind: 'tui' }
  if (first === '--web') return { kind: 'web' }
  if (first === 'today') return { kind: 'today' }
  if (first === 'watch') return { kind: 'watch' }
  if (first === 'init') return { kind: 'init' }
  if (first === 'export') {
    const format = argv.includes('--csv') ? 'csv' as const : 'json' as const
    const outIdx = argv.indexOf('--out')
    return { kind: 'export', format, out: outIdx >= 0 ? argv[outIdx + 1] ?? null : null }
  }
  return { kind: 'help' }
}

export const HELP = `burn0 — local API & LLM usage tracker

Usage:
  burn0            open dashboard (terminal UI)
  burn0 --cli      terminal dashboard (explicit)
  burn0 --web      local web dashboard (coming soon)
  burn0 today      one-shot summary of today
  burn0 watch      live tail of requests
  burn0 export     dump metadata (--csv | --json, --out <file>)
  burn0 init       write burn0.config.json with defaults
`
```

`packages/cli/src/format.ts`:
```ts
export function fmtUsd(n: number | null): string {
  if (n == null) return '—'
  return n >= 1 ? `$${n.toFixed(2)}` : `$${n.toFixed(4)}`
}

export function fmtNum(n: number): string {
  return n.toLocaleString('en-US')
}

export function fmtMs(n: number | null): string {
  if (n == null) return '—'
  return n < 1000 ? `${Math.round(n)}ms` : `${(n / 1000).toFixed(1)}s`
}

export function fmtAgo(epochMs: number, now = Date.now()): string {
  const s = Math.max(0, Math.round((now - epochMs) / 1000))
  if (s < 60) return `${s}s ago`
  if (s < 3600) return `${Math.round(s / 60)}m ago`
  if (s < 86400) return `${Math.round(s / 3600)}h ago`
  return `${Math.round(s / 86400)}d ago`
}
```

import { loadConfig, openDatabase, pruneRetention, maybeVacuum, type StorageDriver } from '@burn0/core'

export function openReadDb(): { db: StorageDriver; dbPath: string } {
  const cfg = loadConfig(process.cwd(), process.env)
  const db = openDatabase(cfg.dbPath)
  try { pruneRetention(db, cfg.retentionDays); maybeVacuum(db) } catch {}
  return { db, dbPath: cfg.dbPath }
}

import { query, type StorageDriver } from '@burn0/core'
import { fmtUsd, fmtNum } from '../format.js'

export function runToday(deps?: { db: StorageDriver }): void {
  const db = deps?.db ?? (require('../db.js') as never as { openReadDb: () => { db: StorageDriver } }).openReadDb().db
  const s = query.todaySummary(db)
  const w = (line = '') => process.stdout.write(line + '\n')
  w(`burn0 — today`)
  w()
  w(`  LLM spend:   ${fmtUsd(s.spendToday)}`)
  w(`  Total calls: ${fmtNum(s.callsToday)}`)
  w()
  if (s.topModels.length) {
    w(`  Top models:`)
    for (const m of s.topModels) w(`    ${m.model}  ${fmtUsd(m.costUsd)}  (${fmtNum(m.calls)} calls)`)
    w()
  }
  if (s.topEntities.length) {
    w(`  Top entities:`)
    for (const e of s.topEntities) w(`    ${e.entity}  ${fmtNum(e.calls)} calls  ${e.costUsd ? fmtUsd(e.costUsd) : ''}`.trimEnd())
  }
}

import { writeFileSync } from 'node:fs'
import type { StorageDriver } from '@burn0/core'
import { openReadDb } from '../db.js'

const COLS = ['id', 'project_id', 'entity', 'entity_class', 'provider', 'method', 'normalized_endpoint',
  'hostname', 'status', 'started_at', 'first_byte_ms', 'latency_ms', 'req_bytes', 'res_bytes',
  'model', 'tokens_in', 'tokens_out', 'tokens_cached', 'cost_usd', 'estimated'] as const

export function runExport(format: 'json' | 'csv', out: string | null, deps?: { db: StorageDriver }): void {
  const db = deps?.db ?? openReadDb().db
  const rows = db.prepare(`SELECT ${COLS.join(', ')} FROM requests ORDER BY id`).all()
  const text = format === 'json' ? JSON.stringify(rows, null, 2) : toCsv(rows)
  if (out) {
    writeFileSync(out, text)
    process.stdout.write(`exported ${rows.length} rows to ${out}\n`)
  } else {
    process.stdout.write(text)
  }
}

function toCsv(rows: Record<string, unknown>[]): string {
  const esc = (v: unknown) => {
    if (v == null) return ''
    const s = String(v)
    return /[",\n]/.test(s) ? `"${s.replace(/"/g, '""')}"` : s
  }
  const lines = [COLS.join(',')]
  for (const r of rows) lines.push(COLS.map((c) => esc(r[c])).join(','))
  return lines.join('\n') + '\n'
}
```

import { join } from 'node:path'

const DEFAULT_CONFIG = {
  retentionDays: { payloads: 7, metadata: 30 },
  bodyCapBytes: 1048576,
  ignoreHosts: [],
  capturePayloads: true,
  redact: { extraHeaders: [], disable: false },

export function runInit(deps?: { cwd?: string }): void {
  const cwd = deps?.cwd ?? process.cwd()
  const p = join(cwd, 'burn0.config.json')
  if (existsSync(p)) {
    process.stdout.write(`burn0.config.json already exists — not overwriting\n`)
    return
  }
  writeFileSync(p, JSON.stringify(DEFAULT_CONFIG, null, 2) + '\n')
  process.stdout.write(`wrote ${p}\n`)
}

import { query, type StorageDriver } from '@burn0/core'
import { openReadDb } from '../db.js'
import { fmtUsd, fmtMs } from '../format.js'

export function runWatch(deps?: { db: StorageDriver; intervalMs?: number; maxTicks?: number }): void {
  const db = deps?.db ?? openReadDb().db
  let lastId = query.dbStats(db).maxRequestId
  let ticks = 0

          `${new Date(r.startedAt).toLocaleTimeString()}  ${String(r.status ?? 'ERR').padEnd(4)} ${r.method.padEnd(6)} ${r.entity}  ${r.normalizedEndpoint}${model}${cost}  ${fmtMs(r.latencyMs)}\n`)
      }
    } catch {}
    if (++ticks >= maxTicks) clearInterval(timer)
  }, deps?.intervalMs ?? 1000)
  if (maxTicks !== Infinity) timer.unref?.()
}

import { useEffect, useState } from 'react'

export function usePoll<T>(fn: () => T, intervalMs = 1000): T {
  const [value, setValue] = useState<T>(fn)
  useEffect(() => {
    const t = setInterval(() => {
      try { setValue(fn()) } catch {}
    }, intervalMs)
    ;(t as any).unref?.()
    return () => clearInterval(t)
  }, [])
  return value
}

        </Box>
      ) : (
        <Text dimColor>Payload expired (7-day retention) — metadata only.</Text>
      )}
    </Box>
  )
}

function pretty(jsonStr: string): string {
  try { return Object.entries(JSON.parse(jsonStr)).map(([k, v]) => `  ${k}: ${v}`).join('\n') } catch { return jsonStr }
}

function clip(s: string): string {
  return s.length > BODY_PREVIEW ? s.slice(0, BODY_PREVIEW) + `\n… (${s.length - BODY_PREVIEW} more chars)` : s
}
```

Note: `firstByteMs` may be null on error rows — `fmtMs` renders `—`. `reqTruncated`/`resTruncated` come back 0/1 from SQLite; truthiness works.

import React, { useEffect, useRef, useState } from 'react'
import { Box, Text, useInput } from 'ink'
import { query, type StorageDriver, type TraceRow } from '@burn0/core'
import { fmtMs, fmtAgo } from '../../format.js'

const KEEP = 100
const SHOW = 20

export function NetworkScreen({ db, onOpen }: { db: StorageDriver; onOpen: (id: number) => void }) {
  const [rows, setRows] = useState<TraceRow[]>([])
  const [cursor, setCursor] = useState(0)
  const lastId = useRef(0)

  useEffect(() => {
    try {
      const initial = [...query.traces(db, { llm: true, limit: 10 }), ...query.traces(db, { llm: false, limit: 10 })]
        .sort((a, b) => a.id - b.id)
      setRows(initial)
      lastId.current = initial.length ? initial[initial.length - 1].id : 0
    } catch {}
    const t = setInterval(() => {
      try {
        const fresh = query.liveTail(db, lastId.current)
        if (fresh.length) {
          lastId.current = fresh[fresh.length - 1].id
          setRows((prev) => [...prev, ...fresh].slice(-KEEP))
        }
      } catch {}
    }, 1000)
    ;(t as any).unref?.()
    return () => clearInterval(t)
  }, [])

  const visible = rows.slice(-SHOW)

  useInput((_input, key) => {
    if (key.upArrow) setCursor((c) => Math.max(0, c - 1))
    if (key.downArrow) setCursor((c) => Math.min(visible.length - 1, c + 1))
    if (key.return && visible[cursor]) onOpen(visible[cursor].id)
  })

  if (visible.length === 0) return <Text dimColor>Waiting for requests…</Text>

  return (
    <Box flexDirection="column">
      {visible.map((r, i) => (
        <Text key={r.id} inverse={i === Math.min(cursor, visible.length - 1)}>
          {`${fmtAgo(r.startedAt).padEnd(9)} ${String(r.status ?? '?').padEnd(4)} ${r.method.padEnd(6)} ${r.entity.padEnd(16)} ${r.normalizedEndpoint.padEnd(36)} ${fmtMs(r.latencyMs).padStart(7)}`}
        </Text>
      ))}
    </Box>
  )
}
```

# burn0

Local-first, zero-code observability and cost tracking for Node.js apps.
One import — every outbound API call tracked, LLM costs computed, data stays on your machine.

Think of it as a local Sentry/Datadog for your backend's LLM & API usage — no cloud, no signup,
no proxy. Not a coding-agent tracker (codeburn) and not a proxy (burnlens): burn0 tracks your
*application's* API traffic in-process.

## Quick start

    npm install burn0
    # top of your entry file:
    import 'burn0'
    # run your app, then:
    npx burn0

## Commands

    burn0            dashboard (terminal UI)
    burn0 today      one-shot summary of today's spend and calls
    burn0 watch      live tail of requests
    burn0 export     dump metadata to JSON/CSV
    burn0 init       write burn0.config.json with defaults

Dev-only tool: auto-disabled when NODE_ENV=production (override with BURN0_FORCE=1).
Data: ~/.burn0/burn0.db (SQLite). Payloads kept 7 days, metadata 30 days. Secrets redacted by default.
```
